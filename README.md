# SANVIN Integrated Website

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Keep all HTML, CSS, JavaScript and logo files together in the main project folder (root directory). No separate `assets` folder is required.

## Included pages
- Home
- Gold loan calculator
- EMI calculator
- Repayment schedule
- Apply for a loan
- Application tracker
- FAQs
- Contact

## Important integration notes
This is a front-end integration of the HTML, CSS and JavaScript supplied by the project team. The calculators and demo interactions run in the browser. Application submission, contact enquiries, and application tracking are not connected to a backend/database or real SANVIN systems. The tracker uses sample IDs as indicated on its page. The gold calculator uses a demonstration gold rate/LTV assumption; verify all financial rules and rates with SANVIN before production use.

The original team pages have been retained as separate pages, with all HTML, CSS, JavaScript and logo files stored directly in the root directory. `index.html` is the common landing page and navigation hub.
